# Civora AI Auto-Pilot Extension (Manifest V3)

Autonomous AI browser agent that perceives web portals, clicks buttons, types in inputs, and completes government services automatically with Human-in-the-Loop safety boundaries.

---

## 🚀 How to Install in Chrome / Brave / Edge

1. Open Chrome (or any Chromium browser like Brave, Edge, Opera).
2. Go to `chrome://extensions`.
3. Enable **Developer Mode** (toggle at top-right corner).
4. Click **Load unpacked**.
5. Select the `extension` folder located inside this project:
   ```
   c:\Users\lenovo\Desktop\new idea\Civora AI\extension
   ```
6. The **Civora AI Auto-Pilot** extension icon will now appear in your browser toolbar!

---

## 🎯 How to Use Auto-Pilot

1. Click the Civora AI extension icon in your toolbar.
2. Select your desired service (e.g. **Aadhaar Services** or **PAN Services**).
3. (Optional) Click ⚙️ to enter your Gemini API Key for zero-shot computer vision reasoning.
4. Click **Start Auto-Pilot on Tab**.
5. Civora will inject an in-page floating HUD, automatically move the animated cursor, and execute the form fields and button clicks.
6. When an OTP, Password, or CAPTCHA field is reached, the safety shield will highlight the field and pause for your manual entry, then you can hit **Resume Auto-Pilot**!
